## What this is about

This repository covers both the theory and hands-on practice from my first year of Web Application Development (DAW) in the TRIDENTE program at UTAMED.

I use it as an open technical notebook: broken-down notes to actually understand the why behind each concept, class exercises, assignments, small projects, and reference material I rely on to review and track my progress.

## Structure

| Folder | Content |
|---|---|
| `._databases` | Databases: modeling, logic, SQL, queries, and core concepts |
| `computer_systems` | Computer systems: hardware, operating systems, and architecture |
| `development_environments` | Development environments: tools, setup, and Git |
| `markup_lenguages_and_information_management_systems` | Markup languages: HTML, XML, DTD, and data handling |
| `programming` | Programming: logic and inner workings of the code, mainly in Java |

## What is inside

- Straightforward notes breaking down the logic behind each concept without fluff
- Solved exercises and practical assignments
- Small projects and real code examples
- Tables, diagrams, and quick-reference sheets
- A clear record of what I am learning week by week

## Tech and tools

- Java
- SQL and relational databases
- HTML and XML
- Git and GitHub
- Development environments and terminal

## Goal

Build a solid technical foundation, understand how things actually work under the hood, and keep all practical material organized so I can reuse it in future projects and my portfolio.

Continuously updated throughout the academic year as we move through the syllabus.
